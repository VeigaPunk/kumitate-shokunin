2. **Three pinned gates vs two unpinned resolvers.** `cite-check` and `round-gate` keep `resolveSrcDefault()` unchanged (#4, #5) while `claims-check`/`proxy-check`/`surface-probe` gain a pin; `member-claims-gate.md:23` and `round-close-gate.md` still assert one shared convention. 3. **`probeSections()` is a pin bypass today.** `claims-check.mjs:463`'s default `src = resolveSrcDefault()` has no `self`/pin input; `proxy-check.mjs:1048` happens to pass `src`, so the bypass is latent, not live. 4. **The pin's `git rev-parse` breaks a frozen "no subprocess, no git" claim.** PIN v1 requires `git -C <src> rev-parse HEAD`; `executable-scorecard.md:189-192` advertises "no writes, no network, no subprocess, no git, no lock" and `layer-axes.md:257-259` freezes "no spawn on the measurement path" (#29, #31).
