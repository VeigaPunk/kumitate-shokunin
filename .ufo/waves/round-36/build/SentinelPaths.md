## Findings

**P1 HIGH — the pin's `clone` is an unvalidated code-execution sink.** `surface-probe.mjs:368` takes `pin.clone` verbatim (`resolve()` only), and `:1798-1801` feeds it to `readSightingSurface`/`readDispatcherStatus`, which run `bash <clone>/scripts/ufo-sighting` and `node <clone>/scripts/fleet-dispatcher.mjs`. The sole guard is `HEAD == pin.revision`, and the same file supplies both values, so the check is self-certifying. Fixtures S3 (relative `./evil` executed and forged `src-rev`), S5 (dirty clone: content ≠ commit), S6 (`.git` file redirect), S4/S15/S17/S18 (`GIT_DIR` inherited: assertion reads another repo). Exploit: commit `.ufo/pins/origin.json` with `clone` at an attacker tree and its HEAD as `revision`; CI that runs the gates from the PR checkout executes attacker scripts and prints a plausible `src-rev=`. **Impact:** arbitrary code execution as the gate runner, and verdicts that name a revision whose content was never checked. **Smallest remediation:** `realpathSync` the clone; reject non-absolute/`..` forms; require it under an allowlist root (e.g. `$KUMITATE_ORIGIN_ROOTS`, default `/fast/scratch/kumitate-r36`); `lstatSync(join(clone,'.git')).isDirectory()` (reject `.git` files); run git with a scrubbed env (`PATH,HOME,GIT_CONFIG_NOSYSTEM=1,GIT_CONFIG_GLOBAL=/dev/null,GIT_OPTIONAL_LOCKS=0`, no `GIT_DIR`/`GIT_WORK_TREE`/`GIT_CONFIG_*`) and require `git -C <src> status --porcelain -uno` empty (`SRC_DIRTY`, exit 2) so content is bound to the revision.

**P2 MEDIUM — every JSON pin/known/ratchet read is unbounded and non-type-checked.** `surface-probe.mjs:349`, `claims-check.mjs(ExecClaimsPin):124` + `(ExecFidelity):185` (via `readText`), `proxy-check.mjs:352`, `ExecSurfaceKnown:335`, `:425`. A FIFO hangs the gate indefinitely (S1/S8/S14/S16 — no internal timeout; `timeout 3` → 124), a directory/char-device path is read or refused inconsistently, and a 500 MB file costs ~545 MB before refusal (S2/S9). Default-pin symlink to `/dev/zero` would read unbounded via `existsSync`+`readFileSync` (`surface-probe.mjs:1801`) — not executed (OOM risk), [INFERENCE] from the /dev/null and FIFO runs. **Remediation:** one `readJsonFile(path,{maxBytes:65536})`: `lstatSync(path).isFile()` (no symlink), size cap, then read; refuse as `*_MALFORMED`.

**P3 MEDIUM — the temp state/cache redirect trusts `TMPDIR` and does not clean on signals.** `surface-probe.mjs:403`/`:430`: `mkdtempSync` runs before `try`, so a missing/unwritable `TMPDIR` crashes with a stack and **no verdict** (S20), and the directory is outside `finally` on `process.exit`/signals (S21). `tmpdir()` honors `TMPDIR`, so `TMPDIR=<src>/tmp` puts the dispatcher's state *inside the tree the probe scores* (S19: `…/kumitate-surface-state-*/ufo/marker` observed mid-run) — defeating the wave's “no file under `<src>` is created” proof. **Remediation:** resolve+`realpath` the temp root, refuse if it is under `src` (`STATE_ROOT_IN_SRC`, exit 2), move `mkdtempSync` inside the `try` and fail-closed on `EACCES|ENOENT|EROFS`, and register `process.once('exit'|'SIGINT'|'SIGTERM')` cleanup (SIGKILL aside).

**P4 MEDIUM — the dispatcher child inherits the fleet environment.** `surface-probe.mjs:441-445` spreads `process.env` then sets three vars. `UFO_FLEET_LEDGER_PATH` (and `UFO_CONFIG_PATH`, `UFO_SIGHTING_PATH`) still reach the child; the pinned dispatcher rejects a ledger path outside `UFO_STATE` (`fleet-dispatcher.mjs:460,4013`), so a caller env turns the good pin into `STATUS_REACH` FAIL (S22) — false drift, and it means the child is not hermetic. **Remediation:** pass an allowlist env (`PATH,HOME,UFO_STATE_DIR,UFO_PENDING_WORK_PATH,UFO_PROJECT_ROOT`) rather than `...process.env`.

**P5 LOW-MEDIUM — control characters in read files are echoed into verdict output.** `ExecSurfaceKnown:642` prints `KNOWN_STALE … ${subject}` raw and `ExecSurfacePin:407-410` prints `pin clone ${src}` raw; a `\nSURFACE_PROBE: CLEAN (…)` in either yields a standalone forged clean line on stdout/stderr (S11, and clone form observed at `surface-probe.mjs` refusal: three `SURFACE_PROBE: CLEAN` lines). A consumer that greps for `SURFACE_PROBE: CLEAN` can be fooled. **Remediation:** `JSON.stringify()` or strip `[\x00-\x1f]` in every interpolation of file-sourced strings into a verdict/finding line.

**P6 LOW — a present-but-unusable default pin can silently disable provenance.** `claims-check.mjs(ExecClaimsPin):113-116` (`statKind === 'file'`) and `claims-check.mjs(ExecFidelity):665-686` (`text===null → continue`) treat a directory / unreadable / dangling default pin as “no pin”, yielding `MATCH`/`CLEAN` with no `src-rev` (S7, S12, S13), while `surface-probe.mjs:1798-1801` fails closed on a directory. The gate whose claim is “every verdict names the revision it scored” must not fail open when the pin exists but cannot be read. **Remediation:** `lstatSync` the default path; present-and-not-a-regular-readable-file ⇒ `PIN_MALFORMED` exit 2 (single rule, all gates).
