## Findings

1. **K66ReviewToolV1-1 — medium (latent mis-parse; potential L2 kill).** `sep` requires a trailing `|` (`scripts/routed-ledger.mjs:86`, same regex at :117), so a GFM-valid table whose separator omits trailing pipes (`|---|---`) is mis-read: the routed-section parser emits header and separator as items (:91), and the ledger parser emits a phantom 7-cell `---` row that fails the id check (:189) → false ROW_MALFORMED. Attacks the contract's "a column-0 `|` line that is not a header separator". The frozen counter's `isSep` (ledger66-probe.mjs:88) accepts the pipe-less separator, so on such input tool items ≠ counter items and L2's equality check kills the claim. Zero occurrences in the 11 real routed sections today (Evidence 2). Reproducer: `node build/K66ReviewToolV1/probe1.mjs` (T1/T2 lines). Fix: accept an optional trailing pipe in both sep regexes; add a selftest case.
2. **K66ReviewToolV1-2 — low (false DRIFT).** Header-row skip is content-based (`:119 cells[0] === 'id'`): a row with id literally `id` — legal per the contract's id grammar — silently vanishes, leaving its item UNLEDGERED. Reproducer: probe1.mjs T3. Fix: skip only the first row after `## Ledger` when it matches the 7-cell header signature.
3. **K66ReviewToolV1-3 — low (wrong alarm line, verdict unaffected).** CLASS/RECURRENT round sets use raw `row.round` (:233, :238) without requiring the round to have a spot-check; contract says "seen in >= 4 distinct spot-check rounds". Reproducer: probe1.mjs T7 → `RECURRENT ghost-class rounds=4` while only rounds 90–92 exist (gate still DRIFTs via ITEM_ABSENT). Fix: intersect rounds with the spot-check set.
4. **K66ReviewToolV1-4 — low (gate-weakening flag handling).** Empty `--rev ""` is falsy and silently selects worktree reads (`:153 if (rev)`), violating "--rev reads committed bytes only": a dirty worktree can read CLEAN while the committed tree DRIFTs. Reproducer: fixture runs B vs A (build/probe3.mjs; B's DRIFT was byte-identical to C). Fix: USAGE (or rev-unreadable FAIL-CLOSED) for empty/whitespace `--rev`.
5. **K66ReviewToolV1-5 — low (unrepresentable data).** A quote containing `|` cannot be expressed: a raw `|` breaks the 7-cell split (:118, :120) and the GFM escape `\|` breaks it too (probe1 T9 → `cells=8` ROW_MALFORMED). Live constraint: 3 real items (round 60: 1; round 65: 2) contain `|`, so the L1 must pick pipe-free fragments; neither contract nor selftest documents this. Fix: split/unescape cells on `\|`, or add a documenting selftest case.
6. **K66ReviewToolV1-6 — low (latent CommonMark blindness; shared with the counter).** No fence tracking: a heading inside a fence starts the section (T4), fenced bullets become items (T5), a `#` comment inside a fence ends the section (T12). Zero occurrences in the real routed sections at the freeze and the frozen counter is equally blind (no L2 divergence today); any future spot-check quoting counter output in a fence inside its routed section would phantom-item. Fix: fence-aware scan + selftest cases.
7. **K66ReviewToolV1-7 — low (flag usability; lexical ledger identity).** Absolute `--ledger PATH` resolves as `join(root, PATH)` (reader :142-146; :166; :185) → wrong path → FAIL-CLOSED `ledger-absent` (T8b): the flag is silently unusable with absolute paths. The self-answer ban is lexical (`:215 p === ledgerNorm`), so an alias path (e.g. symlink) to the same ledger file would evade it — contrived. Fix: reject absolute `--ledger` with USAGE or resolve both sides.
8. **K66ReviewToolV1-8 — medium (contract sentences without a selftest case).** The selftest never exercises `main()`: exit 64 and `ROUTED_LEDGER: USAGE <msg>` (:41, :368, :370), unknown-argument, missing-value and non-integer `--from/--to` are uncovered — a main() regression would still print PASS (33/33). Also uncovered: an answer quote ACCEPTED at the ±2 boundary (:220; T6a/b show acceptance, selftest only tests rejections), `ANSWER_DEAD` for an absolute answer path (:215), ROW_MALFORMED branches bad-id (:189), non-numeric round/item (:192), bad class (:195), 8-cell row (:120), the DRIFT `first=<ID>:<detail>` verdict field (:243), markers `*`/`+`/`1)` (:90), first-of-two-routed-headings wins, and the `--ledger` flag itself. Fix: ~10 additional selftest cases — a strengthening under the round ratchet.
