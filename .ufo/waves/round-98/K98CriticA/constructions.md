## The grid the battery draws (why the constructions below are invisible)

Extracted from the counter's own `PADS` table and row generators (`battery-grid.txt`):

* **32 id-cell pad classes**, pad **lengths 0, 1, 2 only** — `MAX_PAD_LEN=2` (the only length-2 pads are
  `SP TAB`, `TAB SP`, `SP NBSP`, `NBSP SP`). No pad of length ≥ 3 is ever drawn.
* Classes: SP, TAB, VT, FF, CR, NEL, NBSP, OGHAM, MVS, ENQUAD, ENSP, EMSP, FIGSP, THINSP, HAIRSP, ZWSP,
  ZWNJ, ZWJ, LS, PS, NNBSP, MMSP, WJ, IDSP, BOM. **Not drawn**: soft hyphen U+00AD, LRM/RLM
  U+200E/U+200F, C0 U+0008/U+001F, Hangul fillers U+115F/U+3164/U+FFA0 — i.e. the drawn set is
  `White_Space` ∪ {6 `Cf` samples}, not all `Cf` and not all non-`Zs` non-ASCII.
* **Ids**: 7-digit nonce (`S` + 7 digits, first digit 1–9), 2-digit, lowercase `s`, trailing alpha, `SS`,
  Arabic-Indic digits. **No id with ≥ 8 digits**; no leading-zero id (arm (d)'s real registry does draw
  `S001`-style ids, so a leading-zero refusal is caught by (d)).
* **Contexts**: 13-field mined and 12-field rows inside `## Registry`, 13-field **rejected only inside**
  (never a rejected row outside), 13-field rows under `## Leads (unopened)`, and 13-field rows before any
  heading. Indents 0–4 spaces, TAB, `SP TAB`, NBSP.
* File literals the tool can fingerprint: the fixture header is the **constant** `# SOURCES — fixture r98`
  (only ids/pins/order are nonce), and every row URL is `https://github.com/o/r/blob/<pin>/x.ts`.
* Truth is derived **from the census on the same file** (`censusTruth()`: DECL = `W03` ids matching
  `^S[0-9]{3,}$`, OUT = `E12` ids, MALF = `E01` ids matching `^S[0-9]{3,}$`).

## Findings

Eight of the nine constructions reach **HELD** while violating R98. The counter is otherwise sane on this
host: `ctl-positive` (my regeneration, sha256 identical to `controls/controls-sha256.txt`) is HELD, and the
do-nothing control is UNMET for the intended reason (`FIX-A BASE exit=1 declared=82/22 extra=60 …
outside=108/28 malformed=82/22`, `exact_out=false exact_mal=false`).

* **F-K98-1 (defect — pad length).** R98's pad class is unbounded (`[ \t]*`); the battery draws pad
  lengths 0, 1, 2 only (`battery-grid.txt: MAX_PAD_LEN=2`). `k98-padcap3` (`[ \t]{0,3}`) is HELD, and on
  `|    S123 |` the census mines the row (`W03`) while the construction refuses it. Confirmed on a second,
  freshly drawn seed (`ac11e862fca3029a`, same tool sha256 `80942f3b…`): HELD.
* **F-K98-2 (defect — pad class is `White_Space` ∪ six `Cf` samples, not "the `Cf` format characters").**
  Drawn: U+180E, U+200B, U+200C, U+200D, U+2060, U+FEFF (plus every `White_Space`). Never drawn: U+00AD,
  U+200E, U+200F (Cf), U+0008, U+001F (Cc), U+115F, U+3164, U+FFA0 (Lo fillers), U+034F. `k98-shy`,
  `k98-c0`, `k98-hangulfill`, `k98-lrmstrip` are each HELD and each declares a row the census reads as
  `E02` (never a row). This is M98-1 repeated one edge further out: the plan's "every … `Cf` format
  character" is six of them.
* **F-K98-3 (defect — id length).** Ids drawn are 7-digit nonce and 2-digit only; `k98-idcap7`
  (`S\d{3,7}`) is HELD while refusing an 8-digit id the census mines (`W03`). Also undrawn: an id with a
  leading zero (caught by arm (d): the real registry has `S001`).
* **F-K98-4 (defect — file-start BOM).** No fixture starts with a BOM (FIX-A's first line is a `P` row; the
  real registry starts `# SOURCES`). `k98-bomstrip` is HELD; with `\ufeff## Registry` the census reads no
  Registry (`OUT=[S001,S002]`, `DECL=[]`) and the tool declares both pins.
* **F-K98-5 (structural limit — truth is the census; duplicate authority).** `censusTruth()` derives DECL,
  OUT and MALF from `sources-census.sh` on the same file, so a tool that delegates to the census is HELD by
  definition: `k98-replay` (keyed on the fixture's constant header literal `# SOURCES — fixture r98`, which
  the counter never varies) is HELD, while the identical construction with the census path unavailable
  declares nothing. Delegate-vs-implement is a judge call: the claim's observable survives, R98's *local*
  rule is not what the arms verify, and the gate would stop working on a host without the census.
* **Negative result (the counter has teeth here).** `k98-rejskip` is UNMET (b=0, e=1→0): FIX-B puts every
  row outside, so the rejected row is exercised by arm (b) as well as by base selftest arm (xxiii). I
  expected a gap on "rejected row outside"; the grid is not thin there.

pure battery extension — no predicate change — so it can land as an r99 counter repair (M98-1 class)
without re-opening R98. Then re-score all 15 controls: every one must keep its expected verdict.
