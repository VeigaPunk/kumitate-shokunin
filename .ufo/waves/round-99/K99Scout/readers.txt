# CLASS LEGEND (the three classes that matter, all measured on this host, node v24.21.0):
#
#   [JS-TRIM]  ECMAScript String.prototype.trim()  (ECMA-262 S276, TrimString)
#              = WhiteSpace (TAB VT FF SP NBSP Zs U+FEFF) + LineTerminators (LF CR U+2028 U+2029)
#              = 25 code points. MEASURED IDENTICAL to the JS regex class \s
#              (class-compare.mjs: "IDENTICAL SETS: true", both size 25).
#              Strips: SP TAB VT FF CR NBSP U+1680 U+2000..U+200A U+2028 U+2029 U+202F U+205F
#                      U+3000 U+FEFF LF
#
#   [BLANK]    POSIX blank class /[ \t]/  (the census `row_pass` gawk trim, gawk 5.4.1)
#              = SP TAB only. 2 code points. MEASURED: gawk `gsub(/^[ \t]+|[ \t]+$/,"",s)`
#              leaves U+00A0 intact (probe: "A<NBSP>B" -> "[A B]").
#
#   [SPACE]    POSIX space class /[[:space:]]/  (the census bash `trim_cell`)
#              = LOCALE-DEPENDENT. MEASURED on this host:
#                LANG=en_US.UTF-8 : SP TAB VT FF CR U+3000 are space; NBSP and U+FEFF are NOT.
#                LC_ALL=C        : SP TAB VT FF CR are space; NBSP, U+3000 and U+FEFF are NOT.
#              => a used-by path padded with U+3000 is trimmed under the host locale but not
#                 under LC_ALL=C. This is the census-internal [[:space:]] vs [ \t] divergence the
#                 plan routes as report-only (disclosed limit 2).
#
#   [JS-RE-\s] JS regex \s — identical set to [JS-TRIM] (25 code points, measured).
#   [RE-BLANK] JS regex /[ \t]/ — identical set to [BLANK].
