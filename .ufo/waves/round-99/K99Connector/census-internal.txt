# Census Internal Reader Measurement: row_pass [ \t] vs usedby_findings [[:space:]]

## Background & Mechanism
The fleet census script `/home/vgpnk/Projects/shokunin/scripts/sources-census.sh` contains two internal table cell readers:
1. `row_pass()` (lines 574-695): Awk implementation using `trim(s) { gsub(/^[ \t]+|[ \t]+$/,"",s); return s }`.
   - Trims strictly POSIX `blank` characters (ASCII SP 0x20 and TAB 0x09).
   - Used for table header, section heading, row fields: id, source, kind, tier, scope, anchor, teaches, status, opened, recheck, usedby.
2. `usedby_findings()` (lines 531-570): Bash implementation using `trim_cell()`:
   ```bash
   trim_cell() {
     local value=$1
     while [[ "$value" == [[:space:]]* ]]; do value=${value#?}; done
     while [[ "$value" == *[[:space:]] ]]; do value=${value%?}; done
     printf "%s" "$value"
   }
   ```
   - Trims using bash pattern matching against POSIX bracket expression `[[:space:]]`.
   - Crucially, `[[:space:]]` in bash pattern matching depends on `LC_CTYPE` / locale:
     * Under `LANG=C`: matches only ASCII whitespace (SP, TAB, LF, VT, FF, CR). Does NOT match NBSP (0xA0) or UTF-8 multibyte characters (such as U+2003 EMSP).
     * Under `LANG=C.UTF-8`: matches ASCII whitespace AND Unicode whitespace characters classified under `iswspace` (including U+2003 EMSP). Crucially, NBSP (`\u00a0`) is categorized as non-breaking space and is EXCLUDED from `iswspace` in glibc C.UTF-8!

## Recommendation for Fleet Scripts
In `scripts/sources-census.sh`, `trim_cell()` should be harmonized with `row_pass()` by trimming POSIX blank `[ \t]` instead of bash `[[:space:]]`:
```bash
trim_cell() {
  local value=$1
  while [[ "$value" == [ \t]* ]]; do value=${value#?}; done
  while [[ "$value" == *[ \t] ]]; do value=${value%?}; done
  printf '%s' "$value"
}
```
This removes the locale dependency between LANG=C.UTF-8 and LANG=C and eliminates the internal reader contradiction within `sources-census.sh`.
