## Comparison semantics

Mapped exactly as the frozen plan's predicate (a)–(f), per row:

| candidate kind | census code |
|---|---|
| ID_FORM (`row`,`id string`) | E02 (same id string, exact) |
| ID_DUPLICATE | E03 |
| ROW_MALFORMED | E01 minus rows that also carry E02 |
| KIND_ENUM / TIER_ENUM / STATUS_ENUM | E05 / E06 / E07 |
| OPENED_INVALID / RECHECK_INVALID | E08 / E09 |
| ROW_OUTSIDE_REGISTRY (`row`,`id string`) | E12 (same id string, exact) |

A row agrees iff all nine checks hold; findings on non-row lines or census lines that cannot be
attributed to exactly one generated row are counted as harness problems (0 for both tools, both seeds).
Census E11/E04/W\* and candidate kinds outside the nine (ROW_FIELD_EMPTY, MINED_UNUSED,
USED_BY_MISSING, TIER_INFLATION, REJECTED_\*, SECTION_MISSING, …) are outside the mapping and ignored,
so mined rows use an existing ASCII path and knowledge dirs are empty.

**Counts arm** (three independent statements, checked on every scored fixture): the census's own
`rows`/`tier.*`/`status.*` counters equal the values implied by my fixture cells (blank-trim model) —
**0 failures** on both seeds; the plan's `counts.rows = census rows − #E02` invariant holds —
**0 failures**; and the candidate's `counts.rows`/`tiers`/`status` equal the same expectation —
**0 failures** (916/916 fixtures). This exercises the two extra `trim(fields[4])`/`trim(fields[8])`
call sites that feed the histograms.

## Critique — counterexamples attempted, residual risk

- **Attempted counterexample (none held).** 105 pad classes × 6 semantic cells with random
  lengths/sides, pad-only cells, long runs (11/16/64/256), two-cell combinations, 12/14-field rows,
  CRLF, mixed CRLF, outside-Registry rows, duplicates, invalid id forms/enums/dates, two independent
  seeds. The candidate's `trim` is byte-for-byte the census `row_pass` class on every observed cell,
  and its `counts` reads (rows, tiers, status) agree on all 916 fixtures. No hidden regression from
  the diff: the only non-selftest change is the helper.
- **Residual risk 1 (visibility, not observed).** The five non-semantic cells (source, scope, anchor,
  teaches, used-by) can produce no *mapped* finding, so a hypothetical un-converted trim call site
  there would be invisible to the counter's predicate and to this differential; their effects land in
  ROW_FIELD_EMPTY / MINED_UNUSED / USED_BY_MISSING / E04-class checks, none mapped. The candidate
  converts the one shared helper and `grep` leaves no per-cell `.trim()` outside `parseArgs`, the
  (already-`[ \t]`) heading trim, and selftest helpers. Smallest safe correction if the round wants it
  pinned: one predicate arm on ROW_FIELD_EMPTY for pad-only cells on those five cells (out of my
  seat's writable scope; reported, not edited).
- **Residual risk 2 (effective CRLF grammar).** Whole-CRLF documents have no *effective* Registry for
  either reader (both compare a heading with a trailing CR against `Registry` using `[ \t]`), so rows
  degrade to E12/ROW_OUTSIDE_REGISTRY rather than being validated. This is pre-existing, unchanged by
  R99, and consistent between candidate and census: of the 9 whole-CRLF fixtures, 5 emit
  E12/ROW_OUTSIDE_REGISTRY on both sides (clean, SP-padded id, two padded non-id cells, and a row in
  Paths) and the other 4 emit nothing on either side (NBSP/ZWSP-padded id, lowercase id, and the
  duplicate pair whose two ids both carry NBSP). Not a C1 defect, but a latent footgun for
  anyone who converts a registry to CRLF.
- **Oracle authority.** The census is operator-owned and internally inconsistent (`row_pass` `[ \t]`
  vs `usedby_findings` `[[:space:]]`), but for the mapped row grammar it is stable: re-running census
  `validate` with `LC_ALL=C` on 128 fixtures (13 minimal + every 8th scored) produced **0** differing
  mapped lines vs `LC_ALL=C.UTF-8` (`receipts/locale.txt`/`locale.json`).
- **Impacted axes.** Operability (C1): no harm observed to the claim's rule; coverage rows: untouched
  (this seat is read-only on the lane). The claim's value remains prospective — my fixture cells are
  synthetic; real registries are ASCII-SP padded (K99Scout's measurement, not mine).
- **Smallest safe correction to the claim:** none required. The candidate implements R99 with the
  census blank class on every cell a mapped code can observe, on both seeds.

## Limits

No LF pad (a cell cannot carry a line break), no NUL outside the excluded J fixtures, no lone
surrogates (not valid UTF-8), edge pads only per cell (interior pads cannot move a `trim` class),
one pad class per cell side per fixture except the K two-cell combinations. Fixtures are synthetic
lanes, not copies of real registries; the real-registry no-regression arm is the frozen counter's (g)
and the harm seat, not this one.
