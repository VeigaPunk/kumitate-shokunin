## Method (independent of the frozen counter)

- **Generator: my own.** `gen100.py` (this seat dir) shares no code or corpus with
  `.ufo/waves/round-100/probe/probe100-c1.mjs` or `make-controls100.py`. It draws a seeded battery of
  507 fixtures/seed: every fixture is a private dir (`SOURCES.md`, per-row `README-<key>.md`,
  `cap.txt`, `reg.json`, `meta.json`). Every read row carries an invalid tier `Z<case><key>` so each
  `E06` line is attributable to exactly one row; every probe id is ASCII `S` + 3–10 digits.
- **Oracle: the live census.** `bash /home/vgpnk/Projects/shokunin/scripts/sources-census.sh validate
  --file <fixture>/SOURCES.md --today 2026-11-07`. `census-valid` = the ids of `E06` lines matching
  `^S[0-9]{3,}$`; per-row read state = the row's tier present in an `E06` line.
- **Tools per fixture per variant.** cite-sources: one run per test row with a README citing that
  row's probe (`CLEAN cited=1` = recognised, `DRIFT ghosts=1 first=<probe>` = not); source-capture:
  one run over the whole fixture with a registry that captures the anchor and exempts every test
  probe (recognised = bound ids not reported `orphan-*`, plus any `uncaptured` id).
- **Variants.** `cand` = the READY pair in `K100ExecTool/` (sha verified before and after the runs);
  `ref` = `ctl-positive` regenerated with `make-controls100.py` into scratch (sha equal to
  `controls/controls-sha256.txt`: cite `865ba7e5…`, capture `59ca1a3b…`); `base` = `git show
  5e2f9856:scripts/{cite-sources,source-capture}.mjs`.
- **Model cross-check.** `gen100.py` independently models `row_pass` (gate, 12 pipes = NF 13, id cell
  trimmed of ASCII SP/TAB only, ASCII id). Model-valid/read sets equal the census oracle on all 990
  in-scope fixtures (`model_vs_census_mismatches=0`), so the battery is census-faithful rather than a
  model artifact.

## Boundaries measured outside R100's 13-field/registry scope (report-only, 12 fixtures/seed)

1. **NUL in the id cell corrupts the census `--file` oracle (defect of the oracle, not the tools).**
   Fixture row: `|\x00S5141 | fixture | …` (`receipts/nul-oracle/row.hex`). Census stderr:
   `sources-census.sh: line 717: warning: command substitution: ignored null byte in input`; census
   stdout: `file\tE02\tS5141` **and** `file\tE06\tS5141 tier=…` — the bash `out=$(row_pass …)`
   capture dropped the NUL, so the E06 line looks valid even though `row_pass` itself rejected the id
   (`E02` proves the trim left `\x00S5141`). Both cand and BASE ghost `S5141` (correct per R100 trim);
   the oracle was the only liar. The frozen counter is safe only because its non-blank pool omits
   U+0000. Receipts: `receipts/nul-oracle/` (input hex, census stdout/stderr, three tool outputs).
2. **NF==13 is load-bearing but not in R100's sentence.** A 13-field row plus an extra pipe, or a
   second row after CR/LS/PS on the same LF record, is `E01` for the census (no E06 at all), while
   both tools read the first id; BASE additionally reads the second id after CR/LS/PS. 5 fixtures/seed,
   one E01 each (`receipts/report-only/observed.txt`). This is the disclosed malformed-row class
   (plan limit 2): R100 explicitly says "for a 13-field row", so it is not a candidate defect.
3. **Section scope.** Whole-file CRLF makes the `## Registry\r` heading fail the census heading trim:
   census emits `E12` only (valid set empty), while both tool generations parse rows (they never
   track sections). 3 fixtures/seed. Disclosed out of claim. A file-start BOM is benign when the
   `## Registry` heading is intact (1 fixture/seed; census and both tools agree).

## Critic findings (counterexample, evidence, axis, smallest safe correction)

- **F1 — oracle identity, NUL.** Evidence: §Boundaries 1. Impacted axis: operability claim's oracle
  validity (a HELD predicate computed from `--file` stdout). Smallest safe correction: keep U+0000
  out of the frozen row-id class (already true) and have any counter reject an `E06` line produced
  from NUL-bearing input as SETUP; **do not change the tools** — R100's "trim ASCII SP/TAB only"
  means the NUL pad is not a row id, and the tools implement that.
- **F2 — duplicate authority/scope, NF==13.** Evidence: §Boundaries 2. The census has two authorities
  for "is this a row" (the gate+id grammar and the 13-field count); R100 encodes only the first.
  Impacted axis: claim scope honesty, not the shipped readers. Smallest safe correction: none for
  C1 as frozen (scope sentence already says 13-field); if line-level identity is ever claimed, add
  "the record has exactly 12 `|`" to the rule and both readers — a new claim.
- **F3 — section scope.** Evidence: §Boundaries 3. Impacted axis: operability breadth (registry vs
  whole file). Smallest safe correction: none for C1; normalising CR in headings or sharing one
  section parser would be new scope.
- **F4 — no hidden regression in the drawn classes.** cand == ref on every in-scope fixture, and the
  BASE diff is exactly the JS-`\s`/`m`-flag class; the candidate narrows BASE's malformed-record
  multi-match (`matchAll` → first match per LF record), which the census rejects as `E01` anyway.
  Live exposure for that narrowing is not measured here (K99ExecSibling's 0/5,555 rows is the live
  datum); no claim-level harm.
- **F5 — duplicate-id draw would make the frozen predicate unsatisfiable (latent; not drawn).**
  Evidence `receipts/latent-duplicate/`: two 13-field rows share `S612345`; the census prints
  `E06 S612345` twice plus `E03 duplicate id` (so the census-valid set contains the id), cite-sources
  CLEANs, and source-capture exits 2 `FAIL-CLOSED reason=sources doc has duplicate row id S612345`
  (the duplicate rule is pre-existing contract behaviour, unchanged by C1). Predicate (b) treats a
  non-CLEAN/non-DRIFT exit as an error, so a future battery draw containing duplicates would score
  b=0 for *every* implementation that keeps that rule — an unsatisfiable counter, not an UNMET claim.
  Smallest safe correction: keep duplicate ids out of every future battery (plan limit 2 already says
  so) and/or make "duplicate id in a battery fixture" a counter SETUP precondition; do not weaken the
  source-capture duplicate rule.

## Residual limits of this seat

  CR/LS/PS/NEL/VT/FF prefix cases.

- Everything is 13-field inside `## Registry` except the report-only malformed/section families.
