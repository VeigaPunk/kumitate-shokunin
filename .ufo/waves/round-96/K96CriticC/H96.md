# H96 — historical-registry differential (seat K96CriticC)

**Verdict: H96 SURVIVES on its stated domain.**
Domain tested = every historical revision of `kumitate-shokunin/corpus/SOURCES.md` (75), every
sibling lane's current registry (21, including kumitate), and 300 seeded mutations of the current
kumitate registry (seed 960096). One boundary class — whitespace outside `[ \t]` inside the row-id
cell — breaks the equivalence; it is absent from all 96 real files, absent from the specified
mutation space, and disclosed by the frozen plan ("Exotic whitespace in the row-id cell (`\s` vs
`[ \t]`, e.g. `|\fS001 |`) is not in the battery"). It is not a falsification of the stated
hypothesis; it is a named prospective limit (routed below).

## Method (scripts in this seat dir)

`rule.mjs` extracts `SOURCES_ROW_RE/URL_RE/PIN_RE/SEGMENT_RE` and `declaredPins()` from a gate file
and calls it as a pure function over the file text read as UTF-8. `diff96.mjs` runs, per file:
the R96 rule, the BASE rule, and `sources-census.sh validate --file` (E12/E01 ids, parallel pool).
Comparisons: `outsideRows` vs census E12 (exact sequence, repeats and order); R96 declared set vs
BASE declared set (exact values) on files whose E12 list is empty; `malformedRows` vs E01 as a
secondary axis.

Fidelity calibration (`evidence/calibration.json`, all true) reproduces, from the same reference
file: the frozen probe's FIX-A outside list `[S901 S007 S020 S011 S020 S021 S022 S023 S024 S025 S028]`,
FIX-A declared 7 inside tokens, `malformedRows [S002]`, FIX-B `[S101 S102 S103]`, and the BASE
control's 15 declared tokens and `malformedRows [S002 S022]` from `controls/ctl-positive.txt`. The
census re-derived FIX-A/B E12 and E01 lists equal the frozen ones before any comparison ran.

## Smallest counterexample (boundary class)

`evidence/boundary/adv-vtab-outside.md`: a 13-field row `|\vS001 | … | mined | … |` under
`## Leads (unopened)`.

- R96 `outsideRows = ["S001"]`, declared pins = 0; BASE declares 1 pin; census E12 = `[]`.
- Same for `|\fS002 |`, `|\u00a0S003 |`, `| S004\r |` (`evidence/boundary/`, `evidence/adversarial.jsonl`).
- Cause: `\s*` / JS `.trim()` vs the census's `[ \t]*` / `[ \t]`-only trim; also splits the E01 id
  string for a 12-field inside row (`malformed ["S006"]` vs E01 `["\u000bS006"]`).
- Reachability: a scan of the 75 revisions + 21 lane registries for a gate-row whose id-cell prefix
  holds bytes outside `[ \t]` returned `scanned_files=96 exotic_idcell_hits=0`
  (`evidence/boundary/whitespace-scan.txt`). Direction is fail-closed for the claim: the gate can
  only withhold pins/over-disclose outside rows relative to the census, never declare an outside
  row's pin.

## Impacted axes and correction

- Axes: operability C1 only (the disclosure count and pin scoping). Coverage untouched; no harm
  dimension exercised here.
- Do **not** change frozen R96 (`SOURCES_ROW_RE` "unchanged") on this evidence. If exact census
  parity is wanted beyond the observed corpora, the smallest future correction is to match and trim
  the outside-row id with the census classes, i.e. detect outside rows with
  `/^ {0,3}\|[ \t]*S[0-9]{3,}[ \t]*\|/` and strip only `[ \t]` from `split('|')[1]`, leaving the
  inside-section path and `SOURCES_ROW_RE` as frozen. Route to a later round; not applied here
  (read-only lane, and the frozen plan anticipates this exact class).
