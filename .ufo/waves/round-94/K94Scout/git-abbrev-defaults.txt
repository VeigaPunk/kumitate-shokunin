$ git help config core.abbrev | head -12
     core.abbrev
         Set  the length object names are abbreviated to. If unspecified or set
         to "auto", an appropriate value is computed based on  the  approximate
         number of packed objects in your repository, which hopefully is enough
         for  abbreviated  object names to stay unique for some time. If set to
         "no", no abbreviation is made and the object names are shown in  their
         full length. The minimum length is 4.

     core.maxTreeDepth
