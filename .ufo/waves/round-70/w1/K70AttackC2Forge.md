# K70AttackC2Forge — scoped findings (AttackC2Forge)

Seat: K70AttackC2Forge · Milestone: AttackC2Forge · Judged axis: operability (C1 replay isolation)
Attack edge: **c2 forgecapture live digest failure is required; network failure cannot count pass.**

## Verdict

CONFIRMED DEFECT (counter under-specification, defense-in-depth gap). The frozen R7 predicate
never inspects the receipt for the digest-arm evidence; the property "live digest failure is
required, network failure cannot count pass" is enforced exclusively by one `grep` line inside
the NON-FROZEN private copy that the implementation generates. If that copy's gate is dropped or
weakened by a substitution defect, a pure network failure (or even a `--no-live` run) is scored
R7 PASS by the frozen counter. The frozen deprec69 counter itself is sound — it distinguishes
`origin-unreachable` / `origin-http-N` / `origin-sha-mismatch` correctly (verified by real
execution).

  never waived"). No other axis touched; no coverage/knowledge claim implicated.

## Root cause

Single point of enforcement outside the frozen counter. R7 trusts `CONTROL-PASS forgecapture`
text generated by the private copy; the copy is the implementation's artifact, not frozen bytes.
The contract's "refuse unexpected frozen source bytes" guards the INPUT to substitution, but
nothing verifies that the digest-arm gate line survived substitution in the OUTPUT copy, and the
frozen counter cannot distinguish `origin-unreachable` from `origin-sha-mismatch` receipts.

## Smallest safe correction (freeze consequence)

The counter is frozen (plan freeze `3dbe7e6e2616423d55f0ea2bbcf8fb32fe7bda6a`) — the predicate
must NOT be amended after scoring and PLAN_BEFORE_READY must not be anticipated. Correction
lands outside the counter, in implementation + close sequence:

1. `control-replay.mjs` generation step: after substitution, assert the generated c2 copy still
   contains byte-exact `grep -q 'S210:origin-sha-mismatch'` and the live LIVEFLAG assignment for
   forgecapture (lines 103–104, 113 of the frozen source); refuse to run otherwise.
2. Runner exit path for `--family c2 --mode forgecapture`: before exiting 0, require the receipt
   to contain `S210:origin-sha-mismatch` AND a `live=exercised` trailer; otherwise exit non-zero.
3. Selftest: add a stable finding id that pipes a synthetic `origin-unreachable` receipt through
   the gate and asserts refusal (hermetic, no network).
4. L1 close sequence: final verification pass greps the archived R7 receipt for
   `S210:origin-sha-mismatch` before recording 10/10; if receipts lack it, record the honest
   miss and disclose the limit (per plan: "limits disclosed rather than changing this predicate
   after scoring").
