### Q83 — a field-line parser must treat invisible-prefix characters as one prefix class, with a positive twin for each class it strips (round 90)

- **Rule.** A parser that reads a receipt's field lines after a leading prefix must declare the prefix set as one named class, taken from the UCD general categories and White_Space it cites. For every member the parser strips, a receipt whose field lines all carry that member must still parse (a positive twin). For every member, a duplicate field line behind that member must be refused (a negative twin). A parser that strips a member without a positive twin, or refuses a receipt because a member is present, is not admitted.
- **Grounding.** Round 89's sentinel found that a mid-file U+FEFF (attack B2) and a U+200B (attack B7) hide a second `cmd=` line: base v2 and the v3 candidate both read `CLEAN` (`.ufo/waves/round-89/build/K89Sentinel/attacks.txt`, rows B2 and B7). The round-89 probe had no arm for a prefixed duplicate; its only BOM arm is the file-leading `bom-rev` (`.ufo/waves/round-89/probe/probe89-c1.mjs:463`). Q82's twin rule covers shapes, and the prefix shape had no arm. The round-90 probe carries duplicate arms for six classes (`dup-feff` … `dup-nbsp`) and single-prefix twins for two (`single-zwsp`, `single-nbsp`), which is why this criterion asks for a twin per stripped class.
- **Who checks.** The L1 before the freeze, comparing the parser's declared set with the probe's arm list. K90ExecAudit (round 90) for the probe itself. A sentinel attack is not a substitute: the round-89 bypass was found after the freeze.
- **Field.** The parser's header names the prefix set and cites the UCD rows (general category or White_Space) that each member comes from. The probe has one `dup-<class>` arm and one `single-<class>` arm for each declared member.
- **Command.** From the lane root, on the probe source: `grep -oE "\['dup-[a-z]+'" .ufo/waves/round-<N>/probe/probe<N>-c1.mjs | wc -l` and `grep -oE "arm\('single-[a-z]+'" .ufo/waves/round-<N>/probe/probe<N>-c1.mjs | wc -l`. Both counts must equal the number of declared members. On a candidate: `node .ufo/waves/round-<N>/probe/probe<N>-c1.mjs --lane . --work "$HYAKU_SCRATCH/x" --rev <rev> --tool <candidate> | grep -E '^ARM (dup|single)-[a-z]+: '` must print PASS for every line.
- **Fails when.** A declared member has no `single-` arm; a `dup-` arm for a declared member reads `CLEAN`; a receipt whose field lines all carry one member is refused; the set is declared without a cited UCD row.
- **Shown able to fail.** On the round-90 probe, the source counts are 6 `dup-` and 2 `single-` for a six-member set. The count fails for the four members without a single twin (U+FEFF, U+200C, U+200D, U+200E). The base v3 instrument at `7218699cfbdec702ba42f35ceac0a8e52d1bd564` prints `ARM dup-zwsp: FAIL` and `ARM single-zwsp: FAIL` (`.ufo/waves/round-90/K90ScribeLesson/evidence/probe-base-v3-direct.txt`), which is the expected failure for an instrument that strips no prefix.
- **Positive direction.** The sentinel's B7 bytes (a receipt whose second `cmd=` line starts with U+200B) must read `FAIL-CLOSED AMBIGUOUS_FIELD` under a conforming parser; the same bytes read `CLEAN` under base v2.
- **Limit.** The criterion binds what the parser declares and what the probe tests. It does not check that the declared set is complete. The Unicode check is separate: U+200F is Cf and sits outside the six-member v4 set (`.ufo/waves/round-90/K90ScribeLesson/evidence/unicode-classes.txt`). A completeness criterion (every `\p{Cf}` member inside the declared set, or an explicit bound with a reason) is not part of Q83 and needs its own entry if the lane wants it.
