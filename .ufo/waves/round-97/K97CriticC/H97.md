## Method (harness.py in this directory)

Per case: `bash /home/vgpnk/Projects/shokunin/scripts/sources-census.sh validate --file <f>` →
E12 ids in output order; `... census --file <f>` → `rows`; tool
`node <tool> --self <case dir> --today 2026-11-07 --json` → `ROW_OUTSIDE_REGISTRY` ids in finding
order + `counts.rows`. Comparison is order-sensitive list equality plus rows equality. Every
later git call used `git -C <lane>` / `git show <rev>:…` read-only; no lane mutation.

Cases (built from frozen lane bytes; `cases-metas97.json`, `cases-metas197.json`):

* `hist/` 76 ×2 — `git log --format=%H -- corpus/SOURCES.md`, each blob via `git show <rev>:…`.
* `sib/` 21 ×2 — every `/home/vgpnk/Projects/shokunin/*-shokunin/corpus/SOURCES.md`.
* `mut/` 300 (seed 97) and 300 (seed 197) — seeded line mutations of the freeze registry:
  heading insert/delete/replace/move (`## X`, `# X`, `### X`, `##\tRegistry`, `## Registry\r`,
  `## Registry\v`, `\f`, NBSP, `##  Registry`, `## registry`, `## Registry ##`, `#`, `# `,
  0–4-space and tab indents), random rows moved between sections, CRLF blocks and whole-file CRLF.
  Class coverage seed 97 / seed 197: CRLF-or-trailing-CR 78/68, indented heading 14/21,
  tab-indent heading 10/5, `##\t` 12/3, VT 11/12, FF 3/7, NBSP 25/21, `###` 10/6, `#`-only 4/11.
* `stress/` 240 ×2 — 40 heading shapes × 6 indents, minimal two-row fixture (one row before and
  one after the heading), isolating one grammar clause per case.
* `probe/`, `probe2/` 27 — supplementary, outside the assigned corpus: 8 row-definition cases,
  11 exotic files (empty file, heading-only, no heading, BOM, NUL, CR-only endings, CRLF without
  final EOL, U+2028/U+2029 trailing, NBSP/VT/FF before `##`), 8 degenerate files.

## Known limit (pre-existing, shared with BASE and the L1 rule; not R97's delta)

The census `rows++` counts **every** table row inside `## Registry` (gawk `row_pass`:
`separator_row` skip, no id test); the tool counts only ids matching `^S\d{3,}$` and reports other
rows as `ID_FORM`/`ROW_MALFORMED`. Probe result: census rows 2 vs tool rows 1 on 5/8
row-definition probes, for BASE, ctl-positive **and** candidate alike; E12 ids agree 8/8 there.
R97 explicitly freezes row detection at base, so this is not introduced by the change — but a
future claim that `counts.rows` equals census `rows` in general would be false.
