## Findings
- K64ReviewProbeC2-1 (HIGH, attacks J3 "committed capture"): `rd()` is `readFileSync(join(T, c.path))` with no confinement — `..` segments and committed symlinks escape the archive. Fixture S198 pin `../kumitate-r64/…/host-capture.txt` passed J3; mutating the host file flipped the verdict at a fixed rev. Repro: repro-notes §1/§3.
- K64ReviewProbeC2-2 (HIGH, attacks J4/J5 quote floors): `norm()` maps a markup-only quote to `""`; `capText.includes("")` and `live.includes("")` are always true, and J4/J5 only require `bullets.length>0` globally plus per-row presence of SOME bullet. Bullets `- S198 — "**"` counted toward the >=4 floor and passed a real live fetch. Repro: fixture entry bullets 3–4, run held=7/8.
- K64ReviewProbeC2-3 (HIGH, attacks J6 "fresh-fixture demo" + "in the archive"): `spawnSync('bash', [join(T,'scripts','jj-seat-demo.sh')], {timeout:120000})` has no `cwd: T` (J7's readme-map run does) and no containment — the demo inherits the caller's cwd and, via committed symlink, may be a mutable host file. Echo-only demo printed 16 `JJ_SEAT` keys and passed; `probe_cwd=$(basename $PWD)` proved cwd-dependence; symlink repro proved post-commit mutation changes the verdict. Repro: repro-notes §1/§2/§4.
- K64ReviewProbeC2-4 (HIGH, attacks J7 census leg): `CENSUS = env.SOURCES_CENSUS || <fleet path>` — an env var silently replaces a frozen check, and the default is an unpinned fleet script outside the freeze. Committed SOURCES.md with `E03 duplicate id` passed J7 under a `exit 0` stub. Repro: repro-notes §5.
- K64ReviewProbeC2-5 (MED, plan/code mismatch J8): plan requires the AMENDMENT SECTION to name entry+M7; code tests `tail.includes(ENTRY)&&/\bM7\b/` over all appended bytes and only requires a heading match — `…entry… M7\n\n## Amendment 2026-10-25\n(empty)` passes. Also J8 compares `git show BASE` raw bytes against `git archive M` attribute-converted bytes: a tip `*.md eol=crlf` makes an honest append read `base-bytes-not-a-prefix`; `export-subst`/`export-ignore` desynchronise both reads the same way (bytes in Evidence).
- K64ReviewProbeC2-6 (MED, J6 parser fragility): stated value strips trailing whitespace, live doesn't (`v` vs `v   ` → MISS); live CRLF lines match nothing (`.` vs `\r`) → `stated-not-live`; keys restricted to `[a-z0-9_]+` while plan says `<key>` unqualified (camelCase/hyphen keys silently dropped); `### ` subheadings are not terminators (bullets under them counted); duplicates collapse (Map last-wins). Demo stdout >1 MiB → `ENOBUFS`→`demo-exit=null` MISS (no maxBuffer set). All verified by node -e, Evidence list.
- K64ReviewProbeC2-7 (MED, J1 provenance scope): `ids` are harvested only from the first 14 lines (`head`); a `source: S999` line below line 14 is never checked by J2–J5 — an entry can cite unverified rows. `verified-at` regex lacks an end anchor (`2026-10-25xyz` passes). Repro: node -e Evidence.
- K64ReviewProbeC2-8 (LOW, J5 fetch semantics): only the FIRST URL in a source cell is fetched; trailing punctuation (`x.txt.`) is captured → 404 → false `live-unreachable` MISS; 403/rate-limit = MISS per plan (verified exit 22); redirects pass (exit 0); a cited row whose live fetch fails makes ALL its bullets skip, but J4's per-row bullet floor still binds it, so no full evasion.
- K64ReviewProbeC2-9 (LOW, plan/code mismatches, stricter/weaker): J7 `named` accepts any line containing the entry path plus the substring `band` — `- abandoned: <entry>` passes; J2 `usedBy.includes(ENTRY)` accepts `…md.bak`; J2 adds `tier === ''` MISS not in plan (stricter, benign); `bullets.length<4` correctly implements plan `>=4` (the r63→r64 change is a match, not a defect); `--entry`/`--opened` values are accepted but never echoed in the verdict line (receipt ambiguity); `--entry` as last arg → `rd(undefined)` → caught → `entry-absent` (fail-closed).
- K64ReviewProbeC2-10 (LOW, control script): `jj-donothing-control.sh` `|| true` records `exit=0` where plan declares `exit 1` and sibling receipt shows `exit=1` — receipt/exit-evidence mismatch; it also reads the staged entry from mutable `~/Projects/shokuknow` (currently `verified-at: 2026-10-24`, consistent with the receipt's `verified-at=false`), so the control output is not frozen-reproducible.
